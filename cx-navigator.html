BRIEF HIGHLIGHTS

Deloitte’s CX teams spend the first 2 weeks of every client project turning research data into personas, journey maps and an executive summary. CX Navigator simplifies how consultants build CX deliverables, offering persona generation, journey creation and mapping, and an experience score dashboard from a single data upload.

KEY PRODUCT DECISIONS & SOLUTIONS

CX Navigator is strategically human-in-the-loop by design. The tool drafts personas, journeys and scores, while the consultant checks the data reading, edits the journey and approves what reaches the client

Sign In

The CX Navigator is an internal Deloitte tool and does not require the consultant to update a new password

Single Sign On feature has been enabled

CX Navigator: All Projects

Organised work as a grid of project cards, to find an engagement by scanning logos and names.

Showed owner, dataset count and date on every card, to know who owns a project and how current it is can be read without opening it.

Kept search, pinned projects and a persistent Create New Project action in place, to enable returning users get back to their work quickly and new projects start from the same screen.

CX Navigator: Project Setup & Data Upload

Combined project details and data upload on one screen for faster project set up and readiness to generate personas in a single step.

Input four types of data sheets - Interview, CRM, Survey and Ticketing to generate 6 different data-driven personas.

Added a dataset preview with a plain-language description of each column to confirm what was uploaded before the personas are built.

CX Navigator: Personas

Presented the six personas as comparable cards, with the same attributes on each to weigh segments before opening one.

Linked each card to a full profile that opens with the same hero image and name to know which persona they are in.

Grouped the profile into labelled blocks and closed with personality tags and mood images for a long persona can be scanned and still feel like a person.

CX Navigator: Journey Mapping

Structured the journey as four tiers (phases, stages, steps and needs), each with its own colour and running count, so a long journey stays readable at any depth.

Stamped each item with who added it and when, alongside a Users control, to trace a journey built by several people.

Added Spotlight to focus on a chosen phase, stage or step, to showcase or work on one part of a large journey without losing the whole.

CX Navigator: Score & Dashboard

Anchored the dashboard on one Overall Experience Score, with the current and potential score shown together, for easy gap visibility and to view recommendations.

Linked the score to the persona collection and the number of people in each, to see who a score applies to and how large each segment is.

Broke the score down into individual pain points, filterable by phase, stage and step with a colour-banded Top 10 view, to move from the overall picture to the critical moments, then export the result.

LEVERAGING AI CAPABILITIES OF TODAY

Speculative CX Navigator Features

Where AI Stops

Data flags to flag duplicate IDs, mismatched files and skewed or thin samples before personas are generated, so users trust the data behind every score.

Assisted AI never removes a data row without the approval of human-in-the-loop for every flag.

Journey mapping agent drafts phases, stages, steps and needs from the uploaded interviews and surveys, each linked to the data it came from to give users a headstart.

To tackle LLM hallucination, the agent can only propose a suggestion which is either approved or rejected by the human-in-the-loop.
