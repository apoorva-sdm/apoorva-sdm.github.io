OVERVIEW

The Everest Agentic AI Admin Portal simplifies how AI agents are created, offering a guided agent builder alongside built-in monitoring and analytics for continuous improvement. Complex technical decisions such as embeddings, retrieval patterns and hyper parameters were translated into a guided seven-step flow built on plain-language questions, archetypes and templates, fast-tracking Everest teams towards accessibility. Transparency and human oversight were designed into every step, from visible pipeline processing to recommendations the admin can override. The design as shaped through worked closely with an AI Consultant from Deloitte and the business and tech team stakeholders from Everest to ensure a precise UX strategy and product flow, a billable Phase 1 proof of concept that secured Phase 2.

FINAL DESIGN SOLUTIONS AND KEY DECISIONS

ERP Landing

Launchpad for AI agents and a guided agent configurator following the order of a retrieval pipeline.

Reused one card pattern for templates and created agents, to read both the template and the agent built from it as the same thing

The navigation reflects the agent lifecycle (Library, Datasets, Analytics) to support returning users.

Q&A Builder Template: Data

Split agent creation into seven steps, to show users the whole path and their progress up front.

Running summary panel to enable earlier choices to stay visible instead of being remembered.

Designed upload for progress, failure with retry, and success, helping users from error recovery.

Q&A Agent Builder: Prompting

Prompt strategy offered as five named options, turning a technical choice into one selection.

Paired a template library with a build-your-own route, and guided and custom paths now share one screen with auto-recommendations to switch between the two.

Surfaced the embedding, chunking and intent choices beside the prompt form, to see how the prompt fits the pipeline being built.

Q&A Agent Builder: LLM

Placed task and model first as plain selections, to enable user decisions to what the agent does before tuning how.

Collapsible and grouped hyperparameters designed to keep advanced control available without crowding the screen.

Final configuration step consists of a summary and tags in view for a quick sanity check of the whole setup before proceeding.
